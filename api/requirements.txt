# This bundle serves the GROUNDED + LLM + resume endpoints:
#   - About Company / Top Asked  -> google-genai (Google Search grounding)
#   - Ask Puddy / extraction      -> langchain-groq (primary) + langchain-google-genai (fallback)
#   - Resume analyze              -> pymupdf (PDF text extraction)

#   - sentence-transformers / torch  -> embedding + reranker models are local-only
# backend/db/vector_store.py and backend/rag/reranker.py guard these imports in
# try/except, so the app boots and degrades gracefully without them.
# ============================================================
